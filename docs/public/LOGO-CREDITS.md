# Logo credits

All logo files are original work owned by the project.

- `hero.svg` is the docs home page hero image: a sample mindmap drawn as neurons, with the root task as the cell body and its steps joined by axons.
- `logo.png` (used in the README) is made from an original image of glowing nodes joined by lines on a dark background. The project owner provided the image. It was converted from a 1024×1024 JPEG to a 512×512 PNG and is otherwise unchanged.
- `icon.svg` is a simplified vector icon in the same style. It is used as the docs nav logo and favicon.
- `favicon.png` is `icon.svg` rendered at 64×64, for browsers and tools that can't use SVG icons. Re-render it whenever `icon.svg` changes.
